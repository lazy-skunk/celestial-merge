# 天体マージ

同じ天体を重ね、月から太陽まで進化させる物理パズルゲームです。

クリックまたはタップで天体を落とします。同じ天体が接触すると次の天体へ進化し、危険ラインを越えるとゲームオーバーです。

## 起動方法

DockerとDocker Composeが必要です。リポジトリをクローンしたら、プロジェクトのルートで次を実行します。

```bash
docker compose up --build
```

ブラウザで <http://localhost:5173> を開きます。

別のポートを使う場合は、`.env.example`を`.env`へコピーして`VITE_PORT`を変更してください。

## 操作方法

- マウスを動かすか画面をタッチして、天体を落とす位置を決めます。
- クリックまたはタップで天体を落とします。
- 同じ天体同士を接触させると、次の天体へ進化します。
- 天体が危険ラインを越えた状態で留まるとゲームオーバーです。

## 停止方法

起動したターミナルで `Ctrl+C` を押した後、コンテナ、イメージ、ボリュームを削除します。

```bash
docker compose down --rmi all --volumes
```
